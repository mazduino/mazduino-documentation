Dokumentasi Mazduino¶

Selamat datang di dokumentasi resmi Mazduino. Mazduino membuat perangkat manajemen mesin standalone open-source berbasis mikrokontroler ARM Cortex beserta perangkat pendukungnya.

ECU¶

Engine Control Unit standalone berbasis ARM Cortex, dikonfigurasi lewat Mazduino Tuner atau TunerStudio. Mazduino mengembangkan firmware sendiri berbasis rusEFI, dan itu yang disarankan agar seluruh fitur board terpakai optimal. Sebagian board juga dapat menjalankan Speeduino, tetapi pengembangannya sudah dihentikan — lihat tabel kompatibilitas.

Download Firmware ECU¶

⬇ Download Firmware Mazduino di GitHub Releases

Setiap release berisi satu file .zip per board target, misalnya rusefi_bundle_mazduino-mini6ch.zip. Isi tiap bundle:

  • rusefi.bin — firmware siap flash
  • File .ini TunerStudio yang matching — selalu gunakan dari rilis yang sama dengan firmware
  • Script flash (DFU dan ST-Link) dan rusEFI Console

Catatan rilis di halaman release menjelaskan perubahan dari versi sebelumnya. Board target mana yang cocok untuk ECU Anda ada di tabel kompatibilitas. Panduan lengkap cara flash ada di halaman Downloads, atau update langsung dari Mazduino Tuner.

Firmware untuk Racedash terpisah dan diperbarui lewat aplikasi DashTune atau Mazduino Flasher — lihat halaman dash masing-masing.

Model¶

Mazduino LITE¶

Solusi ECU compact terbaru untuk engine 4-silinder dengan Wasted Spark builtin IGBT dan fitur modern.

Fitur Unggulan:

  • 4 channel injector + 2 channel ignition
  • 168 MHz ARM Cortex-M4 processor
  • Support Hall/Optical dan VR sensors
  • 6 analog inputs + 5 digital inputs
  • CAN Bus, USB Type-C, Serial communication
  • SD card data logging
  • Konektor Yamaha 33-pin

Ideal untuk:

  • Engine 4-silinder (NA, Turbo, Supercharged)
  • Street dan track applications
  • Motorcycle high-performance

Mazduino Compact 4ch¶

Engine Control Unit 4-channel yang kompak, dirancang untuk mesin yang lebih kecil dan aplikasi dengan keterbatasan ruang.

Mazduino Compact 4ch v1 Mazduino Compact 4ch v2.3

Fitur Umum:

  • 4 channel injeksi
  • Faktor bentuk kompak
  • MCU ARM Cortex-M4 168 MHz
  • Firmware rusEFI; Speeduino teruji di v1

Firmware rusEFI Mazduino (mazduino-compact) mengikuti pin v2.5 dan v2.3. Pada v1, v2.1 dan v2.2, pin TPS perlu diubah — lihat pin yang perlu diubah.

Versi yang Tersedia:

  • v1 - Konektor Microfit 30-pin (2x12 + 2x3)
  • v2.1 - Konektor Yamaha 33-pin + Knock Sensor
  • v2.2 - High Side Switching untuk alternator/VVT control
  • v2.3-v2.4 - Pin mapping yang dioptimalkan, perbaikan knock sensor, dan RTC battery support
  • v2.5 - Dual high side output, optimasi Hall Input, dan optimasi Analog Input — versi terbaru

Mazduino Mini 6ch¶

Engine Control Unit 6-channel berfitur lengkap untuk kontrol injeksi sequential penuh.

Mazduino Mini 6ch Mazduino Mini 6ch New Case

Fitur Umum:

  • 6 channel injeksi
  • Operasi sequential penuh
  • MCU ARM Cortex-M4: 168 MHz sampai v1.3, 180 MHz mulai v1.3B
  • Kemampuan I/O yang diperluas
  • Firmware rusEFI; Speeduino hanya sampai v1.3B

Firmware rusEFI Mazduino (mazduino-mini6ch) mengikuti pin v1.3C dan v1.3D. Pada revisi sebelumnya, beberapa pin perlu diubah — lihat pin yang perlu diubah.

Versi yang Tersedia:

  • v1.0-v1.2 - Versi standar dengan fitur dasar
  • v1.3 - Dengan Knock Input dan Electronic Throttle Body (ETB)
  • v1.3B - MCU lebih cepat, input analog TPS2 tambahan, dan optimisasi hardware
  • v1.3C - Optimisasi pin MCU, knock input tunggal, dan VDrive ignition terpisah untuk channel 1-4 dan 5-6
  • v1.3D - Pembacaan sensor analog lebih stabil dan terminasi CAN onboard; pinout sama dengan v1.3C - versi produksi terakhir
  • v1.4 - Bukan versi produksi (dokumentasi referensi); versi produksi terakhir adalah v1.3D

Mazduino Core¶

ECU generasi baru berbasis konektor otomotif 48-pin dengan arsitektur I/O yang lebih lengkap dari lini Mini 6CH, dilengkapi dual ETB, dual CAN bus, dan kombinasi input Hall + VR.

Fitur Umum:

  • MCU ARM Cortex-M4 180 MHz
  • Dual ETB (ETB1 & ETB2) dan Dual CAN Bus
  • Kombinasi input Hall/Digital dan VR
  • Konektor otomotif 48-pin
  • Firmware rusEFI based (mazduino-core)

Versi yang Tersedia:

  • rev0 - Versi pertama
  • rev1 - 12V sensor supply, 5V supply hingga 3A, dan opsi jumper tambahan — versi terbaru

Mazduino Mega100¶

Board MCU STM32F407 berukuran Arduino Mega yang dipasang di board Speeduino sebagai pengganti Arduino Mega, sehingga board Speeduino bisa menjalankan firmware rusEFI Mazduino.

Fitur Umum:

  • MCU ARM Cortex-M4 168 MHz, versi 1 MB dan 512 KB
  • 16 input analog dengan buffer untuk sensor 0–5V
  • USB, slot microSD, dan CAN bus
  • Preset pin untuk board Speeduino populer, dipilih dari TunerStudio

Mazduino X600¶

ECU dengan layar 4.3 inci terintegrasi — unit dash dan ECU menjadi satu, sehingga tidak memerlukan dash display terpisah.

Dash Display¶

Layar digital yang menampilkan data ECU secara real-time — RPM, gigi, kecepatan, dan pembacaan sensor. Dash membaca data dari ECU lewat CAN Bus atau Serial; ia tidak mengendalikan mesin.

Mazduino Racedash¶

Racedash 3.5" / 4" Racedash Pro Dash R4

Varian yang Tersedia:

  • Racedash 3.5" & 4" — Konektor JST 4 Pin (3.5") dan DTM4 (4"/Cabus)
  • Racedash Pro — M4, M5, M7 (4.3", 5" & 7") — Layar lebih besar, pengaturan lewat aplikasi DashTune
  • Dash R4 — Layar bulat 4" dengan layar sentuh dan tema dari Theme Store DashTune

ECU yang didukung: rusEFI, Haltech, MaxxECU, Speeduino, OBD-II, dan lainnya — daftar lengkap dan cara mengatur ECU ada di Konfigurasi ECU. Untuk OBD-II hanya varian CAN Bus (ISO 15765-4) yang didukung dan tidak semua mobil dapat dibaca — lihat batasannya.

Cara mengaturnya berbeda antar varian:

  • Racedash 3.5" & 4" — lewat aplikasi DashTune melalui WiFi yang dipancarkan dash (panduannya). Cara lama lewat browser masih ada untuk yang belum bisa memakai DashTune.
  • Racedash Pro M4 / M5 / M7 — lewat aplikasi DashTune melalui Bluetooth, atau dari layar sentuh dash itu sendiri. Varian ini tidak dapat diatur lewat browser.
  • Dash R4 — lewat aplikasi DashTune melalui Bluetooth.

Aksesori¶

Modul tambahan yang terhubung ke bus CAN yang sama dengan ECU dan dash.

  • WBO CAN Controller — wideband oxygen controller untuk sensor LSU 4.9; nilai lambda/AFR dikirim lewat CAN, jadi ECU tidak perlu input analog untuk wideband.
  • CAN IO Extender — menambah input dan output ke Racedash lewat bus CAN, untuk sensor dan saklar yang tidak dibaca ECU.

Software¶

  • Mazduino Tuner (alpha) — software tuning resmi untuk ECU Mazduino berbasis rusEFI. Menu dibaca langsung dari firmware di ECU, dan firmware bisa diupdate dari aplikasi.
  • TunerStudio — software tuning yang juga didukung penuh, memakai file .ini dari bundle firmware.
  • DashTune — aplikasi Android untuk mengatur Racedash dan Dash R4; lihat halaman dash masing-masing.

Memulai¶

Kalau Anda memakai ECU¶

  1. Cek model dan revisi — Lihat versi yang tercetak di PCB, lalu buka halaman dokumentasi revisi tersebut untuk pinout dan wiring
  2. Siapkan sensor dan wiring — Ikuti Persiapan Sensor dan Wiring dan Rekomendasi Ukuran Kabel
  3. Install firmware — Download bundle board target yang sesuai dari github.com/mazduino/mazduino-fw (lihat tabel kompatibilitas), lalu flash sesuai halaman Downloads
  4. Hubungkan software tuning — Mazduino Tuner, atau TunerStudio dengan file .ini dari bundle yang sama
  5. Cek pin — Pada revisi lama, ubah pin sesuai tabel pin yang perlu diubah. Pada Mega100, pilih preset board Speeduino
  6. Mulai tuning — Atur Base Engine Settings, lalu gunakan base map sebagai titik awal dan sesuaikan untuk aplikasi spesifik Anda

Kalau Anda memakai Racedash¶

  1. Pasang dash — Sambungkan ke ECU lewat CAN Bus atau Serial sesuai pinout di halaman varian Anda
  2. Atur ECU — Aktifkan broadcast data di ECU sesuai Konfigurasi ECU
  3. Pilih protokol ECU — Racedash Pro (M4, M5, M7, M7 Pro): pilih di setting dash atau DashTune. Racedash 3.5" & 4" (M1, M2, M3, C1): protokol sudah mengikuti firmware pesanan; kalau ganti ECU, pakai Flash protokol lain di menu Update Firmware DashTune
  4. Pasang DashTune — Daftar sebagai tester di www.mazduino.com/dashtune/tester, lalu pasang dari Play Store
  5. Atur tampilan — Pilih template, data tiap panel, lampu peringatan, dan splash screen dari DashTune

# Mazduino Racedash Pro

## Gambaran Umum

Mazduino Racedash Pro adalah varian dash display digital dengan layar berukuran lebih besar, tersedia dalam pilihan **4.3", 5", dan 7"**. Untuk varian layar 3.5" dan 4", lihat **[Mazduino Racedash](mazduino-racedash.md)**.

| Varian | Ukuran Layar |
| :---- | :---- |
| Racedash Pro 4.3" | 4.3 inch |
| Racedash Pro 5" | 5 inch |
| Racedash Pro 7" | 7 inch |

Custom Firmware Mazduino¶

Firmware Mazduino adalah fork dari rusEFI yang dikembangkan khusus untuk hardware Mazduino. Meskipun berbasis rusEFI, ada sejumlah perbedaan dan tambahan fitur yang tidak ada di firmware rusEFI resmi.

Penambahan dari Official rusEFI¶

Berikut fitur yang ditambahkan pada custom firmware Mazduino:

  • Pin mapping pre-configured — pin bawaan sudah sesuai revisi terbaru tiap board; revisi lama cukup mengubah beberapa pin (lihat pin yang perlu diubah), dan Mega100 memakai preset board Speeduino
  • File .ini TunerStudio disertakan — sudah tersedia dalam setiap release, tidak perlu generate sendiri
  • CAN Virtual Input — bit dalam frame CAN digunakan sebagai digital pin
  • CAN Analog Input — nilai dalam frame CAN digunakan sebagai ADC virtual
  • CAN Sensor Input — override sensor internal (MAP, TPS, CLT, RPM, dll.) langsung via CAN
  • CAN Output — kirim data engine ke bus CAN untuk dashboard atau datalogger eksternal
  • Math Channels (belum tersedia) — kalkulasi channel kustom dari kombinasi channel yang ada
  • User Tables (belum tersedia) — tabel lookup yang dapat dikonfigurasi bebas
  • Logic Outputs (belum tersedia) — output digital yang aktif berdasarkan kondisi yang dapat dikonfigurasi
  • Konsumsi Bahan Bakar — perhitungan L/100km dan L/jam
  • Varian BIGFUEL — tabel VE dan ignition 32x32 dengan hardware yang sama
  • TunerStudio lewat Bluetooth — modul HC-05/HC-06 di semua board
  • AC Idle fuel adder — tambahan bahan bakar saat AC menyala untuk mesin Alpha-N
  • STFT enable switch — short term fuel trim bisa dimatikan dari switch
  • DFCO enable switch — DFCO bisa dinyalakan dan dimatikan dari switch di kabin
  • Temporary Cylinder Shutoff — mematikan silinder sementara untuk mencari silinder yang lemah (dari Mazduino Tuner)
  • Analog Multi-Switch — membaca sampai 16 posisi rotary switch dari satu input analog, 4 switch terpisah
  • Rotational Idle — batas CLT dan TPS yang juga berlaku saat switch ON, stop STFT, tambahan udara idle, dan timing khusus selama aktif

Download firmware ada di halaman Downloads.

Fitur Tambahan¶

CAN Input¶

ECU dapat menerima data dari bus CAN dan menggunakannya sebagai input sensor atau pin digital:

Fitur Kegunaan
CAN Sensor Input Nilai dari perangkat CAN digunakan langsung sebagai sensor (MAP, TPS, CLT, RPM, dll.)
CAN Analog Input Nilai dari perangkat CAN digunakan sebagai input analog (seperti tegangan sensor)
CAN Virtual Input Bit dalam frame CAN digunakan sebagai saklar digital (on/off)

CAN Output¶

Fitur Kegunaan
CAN Output ECU mengirim data engine ke bus CAN — untuk dashboard, datalogger, atau perangkat lain

Komputasi & Tabel¶

Fitur Kegunaan
Math Channels Belum tersedia. Buat channel nilai kustom dari perhitungan kombinasi channel yang sudah ada
User Tables Belum tersedia. Tabel lookup kustom yang dapat diisi dan digunakan dalam konfigurasi

Output Logika¶

Fitur Kegunaan
Logic Outputs Belum tersedia. Output digital yang aktif berdasarkan kondisi yang dapat dikonfigurasi

Konsumsi Bahan Bakar¶

Fitur Kegunaan
Konsumsi Bahan Bakar Perhitungan konsumsi real-time dalam L/100km dan L/jam berdasarkan data injeksi dan VSS

Input¶

Fitur Kegunaan
Analog Multi-Switch Rotary switch banyak posisi lewat satu input analog, dibaca dari curve tegangan

Board dan Koneksi¶

Fitur Kegunaan
Varian BIGFUEL Tabel VE dan ignition 32x32 untuk resolusi tuning lebih rapat, hardware sama dengan board dasar
TunerStudio lewat Bluetooth Tuning tanpa kabel USB lewat modul HC-05/HC-06

Fuel¶

Fitur Kegunaan
AC Idle fuel adder Tambahan bahan bakar saat AC menyala, untuk mesin Alpha-N dengan katup idle bypass
STFT enable switch Switch untuk menyalakan atau mematikan short term fuel trim
DFCO enable switch Switch untuk menyalakan atau mematikan DFCO dari kabin

Diagnostik¶

Fitur Kegunaan
Temporary Cylinder Shutoff Mematikan bahan bakar dan pengapian silinder sementara untuk mencari silinder yang lemah. Hanya ada di Mazduino Tuner

Idle¶

Fitur Kegunaan
Rotational Idle Cut spark atau fuel bergiliran antar silinder untuk suara idle "lumpy"

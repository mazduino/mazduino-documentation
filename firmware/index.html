Custom Firmware Mazduino¶

Firmware Mazduino adalah fork dari rusEFI yang dikembangkan khusus untuk hardware Mazduino. Meskipun berbasis rusEFI, ada sejumlah perbedaan dan tambahan fitur yang tidak ada di firmware rusEFI resmi.

Penambahan dari Official rusEFI¶

Berikut fitur yang ditambahkan pada custom firmware Mazduino:

  • Pin mapping pre-configured — tidak perlu konfigurasi pin manual, langsung sesuai hardware setiap board
  • File .ini TunerStudio disertakan — sudah tersedia dalam setiap release, tidak perlu generate sendiri
  • CAN Virtual Input — bit dalam frame CAN digunakan sebagai digital pin
  • CAN Analog Input — nilai dalam frame CAN digunakan sebagai ADC virtual
  • CAN Sensor Input — override sensor internal (MAP, TPS, CLT, RPM, dll.) langsung via CAN
  • CAN Output — kirim data engine ke bus CAN untuk dashboard atau datalogger eksternal
  • Math Channels — kalkulasi channel kustom dari kombinasi channel yang ada
  • User Tables — tabel lookup yang dapat dikonfigurasi bebas
  • Logic Outputs — output digital yang aktif berdasarkan kondisi yang dapat dikonfigurasi
  • Konsumsi Bahan Bakar — perhitungan L/100km dan L/jam

Download firmware ada di halaman Downloads.

Fitur Tambahan¶

CAN Input¶

ECU dapat menerima data dari bus CAN dan menggunakannya sebagai input sensor atau pin digital:

Fitur Kegunaan
CAN Sensor Input Nilai dari perangkat CAN digunakan langsung sebagai sensor (MAP, TPS, CLT, RPM, dll.)
CAN Analog Input Nilai dari perangkat CAN digunakan sebagai input analog (seperti tegangan sensor)
CAN Virtual Input Bit dalam frame CAN digunakan sebagai saklar digital (on/off)

CAN Output¶

Fitur Kegunaan
CAN Output ECU mengirim data engine ke bus CAN — untuk dashboard, datalogger, atau perangkat lain

Komputasi & Tabel¶

Fitur Kegunaan
Math Channels Buat channel nilai kustom dari perhitungan kombinasi channel yang sudah ada
User Tables Tabel lookup kustom yang dapat diisi dan digunakan dalam konfigurasi

Output Logika¶

Fitur Kegunaan
Logic Outputs Output digital yang aktif berdasarkan kondisi yang dapat dikonfigurasi

Konsumsi Bahan Bakar¶

Fitur Kegunaan
Konsumsi Bahan Bakar Perhitungan konsumsi real-time dalam L/100km dan L/jam berdasarkan data injeksi dan VSS
